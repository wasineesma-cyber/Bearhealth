# ร้านค้าออนไลน์ — ระบบสต็อก + ฟอร์มสั่งซื้อ (แนบสลิป)

เว็บสำหรับขายไพ่พระแม่ / ไพ่ทาโรต์ / กำยาน และสินค้าอื่น ๆ รองรับ **หลายร้านย่อยในระบบเดียว**
ลูกค้าเลือกสินค้า กรอกที่อยู่ ชำระผ่าน PromptPay QR แล้วแนบสลิปได้ในเว็บ
เจ้าของร้านจัดการสต็อกและดูออเดอร์/สลิปได้จากหน้าแอดมิน

## โครงสร้าง
```
ร้านย่อย (Shop)  →  หมวดหมู่ (Category)  →  สินค้า (Product)
```
แต่ละร้านย่อยมี PromptPay / สต็อก / ออเดอร์ ของตัวเอง

## หน้าเว็บ
| URL | ใช้ทำอะไร |
|-----|-----------|
| `/` | หน้าแรก แสดงร้านย่อยทั้งหมดให้ลูกค้าเลือก |
| `/shop/<slug>` | หน้าร้าน — เลือกสินค้า ใส่ตะกร้า กรอกที่อยู่ ดู QR แนบสลิป |
| `/admin` | หลังบ้าน — จัดการร้าน/หมวด/สินค้า/สต็อก และดูออเดอร์ + สลิป |

## การตั้งค่า
สร้างไฟล์ `.env.local` (ดูตัวอย่างที่ `.env.local.example`)
```
ADMIN_PASSWORD=รหัสผ่านเข้าหน้าแอดมิน   # ค่าเริ่มต้น: bearcards
ADMIN_SECRET=สุ่มด้วย openssl rand -base64 32
```

## รัน
```
npm install
npm run dev      # โหมดพัฒนา
npm run build && npm start   # โหมดใช้งานจริง
```

## เริ่มใช้งาน
1. เข้า `/admin` แล้วล็อกอินด้วย `ADMIN_PASSWORD`
2. ที่แท็บ **ตั้งค่าร้าน** ใส่เบอร์/เลข PromptPay และชื่อบัญชี
3. เพิ่ม **หมวดหมู่** แล้วเพิ่ม **สินค้า** (ตั้งราคา/สต็อก/รูป)
4. อยากขายหลายอย่าง กด **เพิ่มร้าน** เพื่อสร้างร้านย่อยใหม่ (เช่น ร้านกำยาน)
5. ส่งลิงก์ `/shop/<slug>` ให้ลูกค้าสั่งซื้อ

## การเก็บข้อมูล
ข้อมูลทั้งหมดเก็บเป็นไฟล์ JSON ในโฟลเดอร์ `data/` (ไม่ commit ขึ้น git)
รูปสลิป/รูปสินค้าเก็บใน `data/media/`
> หมายเหตุ: เหมาะสำหรับเริ่มต้น หากต้องการความทนทานสูง (เช่น deploy บนเซิร์ฟเวอร์ที่รีเซ็ต) แนะนำย้ายไปใช้ฐานข้อมูลภายหลัง
